# Инструкция для агента: установить Widget Reset

Этот файл написан для кодинг-агента (Claude Code / Codex / любой другой),
которому пользователь дал ссылку на репозиторий и сказал «поставь мне это».
Пользователь — владелец Мака, на котором идёт установка.

Выполняй шаги по порядку. Всё, что помечено **[руки пользователя]**, ты
делаешь не сам, а просишь сделать его и ждёшь подтверждения.

## Что это

Виджет для рабочего стола macOS: показывает 5-часовые и недельные лимиты
Claude Code и Codex. Состоит из фонового агента (`Host`) и WidgetKit-расширения.
Собирается из исходников на машине пользователя, подписывается локальным
self-signed сертификатом. Xcode и Apple Developer Program не нужны.

## Чего делать НЕ надо

- Не ставить Xcode.app целиком — достаточно Command Line Tools.
- Не менять bundle ID (`dev.maxterner.WidgetReset*`), они не завязаны на Team ID
  и на чужой машине работают как есть.
- Не подписывать ad-hoc (`codesign -s -`) — тогда Keychain будет запрашивать
  доступ к токену после каждой пересборки. `scripts/install.sh` создаёт
  постоянный сертификат, это осознанное решение (см. `docs/spec.md`).
- Не вводить за пользователя пароли, Apple ID и не проходить логины в CLI.
- Не трогать системные настройки и не отключать Gatekeeper.

## Шаг 1. Проверить систему

```bash
sw_vers -productVersion     # нужно 14.0 или новее
swift --version             # должен отработать без ошибки
```

Если `swift` не найден — **[руки пользователя]** попроси выполнить
`xcode-select --install` и дождаться конца установки Command Line Tools
(GUI-установщик, ты его не пройдёшь). Потом продолжай.

## Шаг 2. Клонировать и установить

```bash
git clone <URL этого репозитория> ~/GitHub/reset-widget
cd ~/GitHub/reset-widget
./scripts/install.sh
```

Скрипт: создаёт сертификат `Widget Reset Signing` (если его ещё нет), собирает
release-бандл, кладёт `Widget Reset.app` в `/Applications` и запускает его.
Занимает пару минут, из них большая часть — первая сборка Swift.

Во время установки может всплыть диалог связки ключей — **[руки пользователя]**,
жать «Разрешить» / «Всегда разрешать».

## Шаг 3. Проверить, что установилось

```bash
ls -d "/Applications/Widget Reset.app"
codesign --verify --deep --strict "/Applications/Widget Reset.app" && echo "подпись OK"
pgrep -fl "Widget Reset.app/Contents/MacOS/WidgetReset"
```

Все три должны отработать без ошибок. Приложение фоновое, окна и иконки в Dock
у него нет — это нормально, ориентируйся на `pgrep`.

## Шаг 4. Логины в CLI — [руки пользователя]

Виджет показывает лимиты того, куда пользователь залогинен. Достаточно одного
из двух, можно оба:

```bash
claude login      # Claude Code: токен уезжает в Keychain, оттуда его читает Host
codex login       # Codex: лимиты берутся через локальный `codex app-server`
```

Это интерактивные браузерные флоу — их проходит сам пользователь, не ты.

При первом обращении к токену macOS покажет диалог доступа к записи
`Claude Code-credentials` — **[руки пользователя]** нажать **«Всегда разрешать»**
(Always Allow). Спросит один раз.

## Шаг 5. Убедиться, что данные поехали

Host опрашивает лимиты сразу при старте и дальше раз в 5 минут. Через
10–15 секунд после логина проверь снепшот:

```bash
cat ~/Library/Containers/dev.maxterner.WidgetReset.Widget/Data/Library/Application\ Support/snapshot.json
```

Должен быть свежий JSON с `usedPercent` и `resetsAt`. Если файла нет —
перезапусти приложение: `open "/Applications/Widget Reset.app"`.

## Шаг 6. Добавить плитку — [руки пользователя]

Правый клик по рабочему столу → «Изменить виджеты» → найти «Widget Reset» →
перетащить маленькую или среднюю плитку.

Если в галерее пусто — попроси открыть `/Applications/Widget Reset.app` ещё раз
и подождать несколько секунд: `chronod` иногда кэширует дескриптор виджета со
второй попытки. Это известное поведение, а не поломка.

## Если что-то пошло не так

| Симптом | Причина и что делать |
| --- | --- |
| `install.sh` ругается на Swift toolchain | Нет Command Line Tools → `xcode-select --install` руками пользователя |
| Скрипт пишет `Нет identity ... подписываю ad-hoc` | Сертификат не создался. Проверь `security find-identity -p codesigning \| grep "Widget Reset Signing"`, при пустом выводе перезапусти `./scripts/install.sh` |
| Keychain спрашивает доступ после каждой пересборки | То же самое: подпись ушла в ad-hoc. Лечится тем же сертификатом |
| Виджета нет в галерее | Открыть `.app` ещё раз, подождать; при упорстве — `lsregister -f "/Applications/Widget Reset.app"` |
| Плитка Claude пустая | Не сделан `claude login` или в диалоге Keychain нажали «Запретить» — тогда запись правится в Keychain Access |
| Плитка Codex пустая | Не сделан `codex login`, либо не найден бинарник `codex` (проверь `which codex`) |
| Плитка висит со старыми цифрами | WidgetKit троттлит перерисовку; снепшот при этом свежий — сверься с `snapshot.json` из шага 5 |

## Обновление и удаление

```bash
cd ~/GitHub/reset-widget && git pull && ./scripts/install.sh   # обновить
pkill -f "Widget Reset.app" ; rm -rf "/Applications/Widget Reset.app"   # удалить
```

Подробности архитектуры и история решений — в `docs/spec.md`, установка глазами
человека — в `README.md`.
