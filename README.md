# Reset Widget

Мак-виджет с лимитами Claude Code и Codex прямо на рабочем столе: 5-часовая
сессия и недельный лимит, проценты и время до сброса — без захода в CLI.

Ни Apple Developer Program ($99/год), ни Xcode не нужны: хватает Command Line
Tools и локального self-signed сертификата, который создаётся скриптом установки.

## Установка

> Ставишь не руками, а через кодинг-агента? Дай ему
> [AGENT-INSTALL.md](AGENT-INSTALL.md) — там пошаговый сценарий с проверками
> и разбором типовых сбоев.

Требуется macOS 14 (Sonoma) или новее и Command Line Tools
(`xcode-select --install`, если ещё не стоят).

```bash
git clone <URL этого репозитория> "Reset Widget"
cd "Reset Widget"
./scripts/install.sh
```

Скрипт создаст сертификат для подписи, соберёт release-бандл, положит
`Widget Reset.app` в `/Applications` и запустит его.

Дальше — три шага руками:

1. **Логин в CLI.** Виджет показывает то, куда ты залогинен: `claude login`
   (лимиты читаются из Keychain) и/или `codex login` (лимиты берутся через
   `codex app-server`). Достаточно одного из двух.
2. **Доступ к Keychain.** Плитка Claude сначала покажет **«нужен доступ»** —
   нажми на эту надпись, macOS спросит доступ к записи `Claude Code-credentials`,
   выбери **«Разрешать всегда»**. Сам по себе диалог не выскакивает: в фоне Host
   читает связку без интерфейса, а с диалогом — только по этому клику. Спросит
   снова, только когда Claude Code перепишет запись (обновит токен и сбросит
   разрешения) — плитка опять покажет «нужен доступ» (см. `docs/spec.md`).
3. **Добавить плитку.** Правый клик по рабочему столу → «Изменить виджеты» →
   «Widget Reset» → перетащи маленькую или среднюю плитку. Если галерея пустая —
   подожди пару секунд и открой `/Applications/Widget Reset.app` ещё раз:
   `chronod` иногда кэширует дескриптор со второй попытки.

Приложение фоновое (без иконки в Dock) и само прописывается в автозапуск через
`SMAppService`. Настройки (звук при сбросе лимита и при достижении 100%) —
ссылка MORE в плитке или повторный запуск `.app` из `/Applications`.

### Обновление до новой версии

```bash
git pull && ./scripts/install.sh
```

Скрипт переиспользует уже созданный сертификат, так что Keychain больше ничего
не спросит.

### Удаление

```bash
pkill -f "Widget Reset.app" ; rm -rf "/Applications/Widget Reset.app"
```

Плитку с рабочего стола убрать вручную; сертификат `Widget Reset Signing`
остаётся в login-связке — его можно удалить в Keychain Access.

## Что где лежит

```
Host/      — фоновый агент: Keychain/codex app-server, опрос лимитов раз в 5 минут,
             запись snapshot.json прямо в контейнер виджета, звуки и уведомления
Widget/    — WidgetKit-расширение: TimelineProvider + SwiftUI-вёрстка, только читает
             снепшот (никаких токенов и сети внутри виджета)
Shared/    — общая Codable-схема снепшота
scripts/   — install.sh (полная установка) и build-widget.sh (только сборка бандла)
docs/      — spec.md: архитектура, обходы ограничений macOS, история решений
```

## Сборка без установки

```bash
./scripts/build-widget.sh          # debug, результат в build/
./scripts/build-widget.sh release
```

Скрипт подписывает identity из переменной `SIGN_ID` (по умолчанию
`Widget Reset Signing`); если сертификата нет — предупреждает и откатывается на
ad-hoc-подпись, при которой Keychain будет переспрашивать доступ после каждой
пересборки.

## Приватность

Токены не покидают машину: Host читает их локально, ходит с ними только в
`https://api.anthropic.com/oauth/usage` (лимиты Claude) и в локальный процесс
`codex app-server` (лимиты Codex), а в контейнер виджета пишет обезличенный
`snapshot.json` — одни проценты и даты сброса. В репозитории нет ни ключей, ни сертификатов — приватный ключ подписи
живёт только в login-связке той машины, где запускался `install.sh`.
